# Original battle-ending primary samples

Imported into an empty destination from the US G8ME01 disc, opened read-only.
`provenance.json` records each original source name, DOL row, MusyX direct
object/macro, sample ID, encoded disc range/hash and decoded PCM hash.

These editable WAV files preserve original mono PCM16 sample rate and amplitude.
Mario's source ending keys are named `SFX_VOICE_MARIO_RELIEF1` and `RELIEF2`.
The star-point cue is `SFX_STAR_POINT_GET1`, originally 16 kHz. No WIN-name
alias, generated tone, normalization, resampling or macro/spatial parity claim.
Normal builds compile these checked-in edits through assets/manifest.json;
the ISO importer must not overwrite them. To recreate an original comparison,
use `tools/import_harbor_ending_audio_assets.py --destination <empty-directory>`.

# Original Mario action voices

Fifteen editable original-rate mono PCM16 samples from the US original game.
See provenance.json for source paths, ISO byte ranges, bank/sample hashes,
original names and effect indirection, decoder and licensing. LICENSE.txt
retains original rights. No redistribution license is granted.

Import only into an empty destination with
`tools/import_mario_action_voice_assets.py --destination <empty-directory>`.
Normal manifest builds preserve these editable WAVs. Playback is a finite
primary-sample native policy, not full MusyX macro emulation.

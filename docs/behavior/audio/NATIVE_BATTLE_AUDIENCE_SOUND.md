# Native audience sound records and ending requests

2026-10-13 binding of [sound bank/clap/stop](BATTLE_AUDIENCE_SOUND_BANK_AND_ENDING_CLAP.md)
and [population/pouch boundary](../battle/AUDIENCE_SETUP4_INITIAL_POPULATION_AND_POUCH_GATE.md).

Portable battle_audience_sound resolves actual inline audience and sound
records through the current packed BattleWork. Half-count scans retain right
then left order and original100-position geometry, live record getters,
existence flag1 with100/2 exclusion and state19 exclusions0c/0d/11. Rank
capacity is not substituted for actual count.

Clap captures its sound record, counts live halves, stops current slot1,
selects original four named keys/category thresholds only for total>=1, then
requests the backend even when the key is unassigned. Actual returned-1 is
stored in record4 and installs no lifetime/volume/active state. Other returned
handles retain source OR1, C+F/F, volume-byte copies and interpolation defaults.
Missing providers return an explicit incomplete-admission result rather than
assigning a fabricated handle. Stop reloads flags after actual backend Off and
clears only1, preserving handle and other metadata. SetVolAll writes all24
records, with raw low8 target, retained multiplier start, duration and cleared
threshold/counter, without inventing an audio stop.

Trio ending now executes both original Clap(-1,0) calls and SetVolAll(0,30),
then Stop(1). The current native records are backed zero initial arena bytes;
full original SettingAudience/RNG/type/entry graph is not yet implemented.
The supplied fresh pouch8c0 forces desired count0, but its original zero-weight
divw path and arbitrary stack key remain unverified numeric/input domains.
These source facts do not constitute universal proof of original silence.

The native unavailable-key backend explicitly rejects an unassigned request
with-1. Structured diagnostic requests preserve absent key, actual counts and
failed result. No C string, original stack bytes or nonnegative playing voice
is invented. This is a best-effort native backend failure adaptation, **not**
proof the original key was valid/unknown or that original playback returned-1.
Known positive-count keys and active nonnegative handles retain their real
positional playback/stop providers; unsupported providers hold their boundary.
No successful DSP/NDSP playback, SoundMain/Noise2 update or interpolation
backend acknowledgment is claimed by record metadata.

Joined/unjoined endings now hold at upper BattleMain800f8e28 after rule and
audience stop. Its remaining subsystem updates/return, lower-wrapper flag
publication, sequence>30, BattleEnd/resources/context/field wait still need
binding. Story/result/control/fade are preserved. No immediate field return.

Tests use owned logical voice fixtures to cover all four tier boundaries,
right/left filtering, source request on count0, failed/unavailable providers,
stop flag reload after backend mutation and all24 volume records. Native
trio regression sees two unassigned failed requests, recordhandleffffffff and
retained30 duration without altered story/result/control. This does not prove
physical audio, original-runtime stack/numeric behavior or full prologue parity.
Original source assets remain private/ignored; no new conversion in this change.

# Original Trouble Center event runtime adapter

The [scoped source pack](NATIVE_TROUBLE_CENTER_DIARY_AND_SCOPED_EVENT_DATA.md)
now has a PMIRAI01 program descriptor: board/counter/installer roots,
confirmation table and21 original callback-address/tag pairs. Descriptor
size196bytes; original205-object/5464-byte PMEVT001 closure is unchanged.
Loader pins original native root/table addresses and all21 source function
addresses, rejects duplicate/missing/swapped tags and retains previous assets
on failure. Each live runtime holds an immutable shared program, so successful
reload does not change an existing event's callback catalog.

TroubleBoardEvent runs actual original words through EventNativeRuntime, not
rewritten lecture/acceptance/cancellation branches. Explicit roots select
board, counter or installer. Constructor is original priority0/defaulttypeef/
flags20. Interpreter owns original child/inline scheduling, label jumps,
comparisons and writes. Source actor/message/case/allocator/audio services are
still external providers, with0 pending/2 completed protocol.

## Known state and callback boundary

Begin requires explicit quest1420 and known GSF5374..5421/GSW1469..1474;
unknown legacy state does not become false/zero. Story and source banks are
seeded into this private VM; public switches is its post-visit snapshot.
The1MiB arena, original-address memory bindings and standalone context are
native provisioning policies, following the existing save-event adapter.
This is not yet the shared field GP/EVT manager or a concurrent global-bank
merge service. Future Game binding must retain the explicit source bank owner.

Callback requests preserve function/event ID, original operands/resolved
values, firstCall, source LW0/LW10/LW11, live story/activeQuest and original
message-ID/name bytes. Installer case requests also retain all16 saved LWs.
No proximity circle, invented NPC, dialogue text or item grant is introduced.
Providers must retain their first request before yielding for delayed resources
or world services; subsequent source polls have first=false. Entire absent
provider gates the manager before it consumes firstCall; waitingForProvider
records that admission boundary. No unbound request returns fake success.

Internal irai_check preservesLW0, publishes source kakunin[Q-1] toLW12, then
freshly readsLW0 intoLW11; cancellation writes0/-1. Native invalid-ID bounds
reject corruption rather than invent a valid task. Internal irai_start clears
only5405..5421 and1469..1474, leaving completion/lecture/1420 to their owners.
MenuInit provider owns actual16748-byte/source0x416c allocation/cache and
returns a retained nonzero opaque pointer forLW10. MenuMain/selection publish
LW0 only on completion. MenuEnd owns mapFree-equivalent cleanup without zeroing
LW10; original menu exit owns its icon deletion. Coin/item-check output operands
remain original references. Cancellation receives live VM working-bank writers
for composition with real pouch services, not a stale public snapshot.

Original source event controls reset/start, nonblocking start child, SET1420
and debug115 order. Debug requests are counted as diagnostics, not gameplay or
an increment. Quest1/4 children remain actual NPC/door requests. Root event ID
and rootAlive are separate from active()/finished: an independently pending
child can keep the runtime active after its parent dies and releases KeyOn.
Case records must inspect their actual root identity; independent child/GP/map
teardown remains required. Copy is disabled; moves rebind the stable runtime
owner at the next visit.

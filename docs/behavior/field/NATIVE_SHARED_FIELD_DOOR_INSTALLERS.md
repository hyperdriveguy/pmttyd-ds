# Shared field scheduler and original door installers

Source: [generic entry and preceding children](GENERIC_DOOR_ENTRY_AND_GOR02_PRECEDING_CASE_INSTALLERS.md),
[case ownership](../overworld/BERO_CASE_POOL_IDS_AND_SWITCH_WRAPPER_LIFETIME.md)
and [outer bank provenance](HOUSE05_OUTER_INIT_BANK_CLOSURE_AND_ROAD_LEAF_CENTERS.md).
The supplied-bank continuation mode remains available alongside the separately
[admitted original parent](NATIVE_ORIGINAL_AREA_PARENT_AND_RETIREMENT.md).

FieldAreaEvent owns one retained EventNativeRuntime and one64-slot FieldCasePool.
It imports the actual door data/EVT bank once and retains cases beyond installer
root retirement. It is noncopyable/nonmovable; its immutable program is held by
shared ownership, and current world services are supplied each tick. No borrowed
Game/door-data owner address is retained across construction or asynchronous use.
A live context free-slot check precedes every constructor. Context initialization
currently supplies256 entries; GP+4=60 is refresh timing, not entry capacity.
Case exhaustion holds the real registration callback without resetting records.

PMFAEV02 contains area-tagged (room,script,record) entries. The current four rows
are source gor02 door02,door03,door03_roll and generic door04. Selection by room
and catalog index avoids global symbol-name ambiguity; catalog indices are not
case IDs. tools/rel_data_pack.py accepts namespace::symbol roots, retaining the
existing requirement that each chosen original object is unambiguous and in a
data section. New areas need their own source-proven roots/tails/providers;
a new entry must not inherit this finite branch-coverage claim automatically.

The converter retains relocated original REL objects with actual adjacent label
scanner context and unchanged generic DOL8033156c/134 plus its adjacent real
word800e8288 at803316a0. DOL script SHA256 is
6269747e7ff14d9effbd84761663f25e880e3ed3c191c842e974db0559e78281.
The initial bank had183 original objects/14304 bytes. The current full-parent
bank has970 REL objects plus61 DOL EVT objects/100520 bytes; PMDRDT01 remains
36 bytes, PMFAEV02 remains60 bytes and PMFAIN01 is20 bytes. Original PPC is not executed.

appendDoorEntry applies the actual outer SET LW0=record and supplies the full
caller bank to a priority0/flags0 root. The original entry words then execute
unchanged. This construction is a native continuation policy; it does not claim
an actual attached-child parent or original same-frame parent scheduling.
The bank is now retained at actual retirement, after recursive child deletion
and copy-back, immediately before clearing. returned distinguishes real RETURN
from forced cancellation. Returned locals may be supplied to the next actual
entry, preserving all high words rather than fabricating them.

fieldDoorParameterEvent implements direct selectors0/1/2/3/6/7/8/9. It captures
args and the resolved record, resolves selector once, and for each output freshly
reads raw destination, then the live record field, then calls evtSetValue.
Negative/unsigned selectors>11 return2 without a record access. Derived geometry
selectors4/5/10/11 hold; no initialized zero tuple is published as a result.
Native record preflight requires a complete bound72-byte record before any
output, an explicit admission policy outside arbitrary guest alias domains.

Named map and hit callbacks consume actual source names and modify the existing
FieldMapFlags hierarchy overlay. Missing or wrong-room providers hold. Case
registration uses the real source wrapper, first-free allocation, original type,
script/priority and16-word snapshot. In an otherwise empty fixture the sequence
allocates seven records, including door02 close LW15=8, ordinary open/close0,
and the distinct type0 roll case. Generic door04 snapshots precede selector9's
final LW1 overwrite. No fixture slot number is claimed as a complete original
area's allocated case ID; preceding area registrations still matter.

All four source record flags are0, so generic door04's bit1 NPC-hide tail is not
executed. A requested hide requires an explicit real provider and may hold; NULL
NPC lists are not acknowledged as empty-list success. No broad callback success
fallback exists. Current case activation is deliberately unexposed: retaining a
script pointer does not establish the complete DOL open/close/sound/light/indirect
script and world-provider closure needed to run that case.

This owner is not yet wired over Game's separate Bero/Trouble runtimes. Source
NPC setup/gazigazi and earlier outer requests remain unbound. House05 has its
own original inline installer, with open LW15=4; generic entry must never replace
it. The full parent now starts in the shared owner with explicit GP input; its
first unbound Bero provider is actual asynchronous pipe prefetch. Next complete
parent/cases/GW record lifetime, share the Bero
and Trouble services, and continue the original house05 installer with the real
returned bank. Coordinated unload must retire events before releasing area data.
The shared core adds no rendering callback; native visibility continues through
existing cached Citro3D ranges. No hardware performance/parity claim is made.

## Four ongoing independent light events

The prefix creates four independent inline roots, binding pointLight1..4 to
S_fune_b with mode0. These roots persist separately from the parent. The original
callback80136158 always returns0 and continues updating each scheduler visit;
it must never return2 or be treated as four blocking attached children.
The parent proceeds to story-dependent audio and later Bero/tag/setup/story
branches. Root/child coverage does not imply those services complete.

fieldLightBindEvent retains complete callback behavior. It resolves light name,
map name and signed mode in source order, then reaches lightNameToPtr8001bcf8
and mapGetMapObj8001f878. Every completed source poll repeats those resolutions.
Native unavailable providers retain the current invocation and its captured
nonzero first flag even when interpreter retry reports first=false.

On first nonzero, it reads actual origin802f3748..50, applies MapObj+1c,
subtracts that transformed origin from Light+3c, and writes raw float bits to
EventEntry+78/+7c/+80. Those scratch words use the existing waitCount/waitStart
ABI fields; there is no numeric float-to-integer conversion. This uses the
base/current matrix, not an inverse matrix.

Every poll rereads its scratch. Mode0 applies actual MapObj+ac. Mode1 reads
MapObj+b8/c8/d8, builds a pure translation matrix and applies it. All other
signed modes skip that transform. It then reads separate origin802f3754..5c,
applies fresh MapObj+1c and adds the two vectors into actual Light+24 XYZ.
Each reached SDK request retains its arguments/output storage through holds;
completed child prefixes and source scratch initialization are not replayed.
The source always ends one poll with0, distinct from an unavailable child.

Lookup and SDK services remain explicit, including original in-place vector
semantics and ordered partial effects. The core does not substitute detached
renderer positions or fabricate light allocation. Native admission requires
stable real map/light storage and event lifetime. The original map unload
frees map objects and clears its light bank; event roots must be retired before
those owners disappear. Actual raw lookup groups, lightEntry/map producers,
map animation publication and downstream GPU light consumers remain required.
Known integer fixture arithmetic is not arbitrary paired-single/FMA parity.

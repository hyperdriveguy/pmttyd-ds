# Harbor battle admission belongs to the original facade

This increment corrects the native facade domain of
[the field sequence identity](NATIVE_HARBOR_FIELD_SEQUENCE.md). It changes no
original PPC body, result value, source memory or story event.

At genuine `HarborTutorial::beginWithContext`, Runtime captures immutable
`nativeAdmissionFacade` and `nativeAdmissionProof` from the actual calling
facade and its `nativeMenuRegistration_`. The separate mutable `scene` pointer
remains the simulation/presentation projection. It is not a birth receipt:
copying HarborTutorial shares its runtime and a copied tick can assign scene.

The sealed field battle identity factory requires the original admission
facade, its current proof and that same current scene projection. Its retained
current/completion closures check the same birth proof before accessing actual
runtime work. A copy cannot mint a substitute identity while the original is
alive, even if the projection is redirected to the copy. Moving or destroying
the original invalidates its admission proof; the destination must hold until
explicit new entry. A fresh independent entry acquires a new proof. Pointer
reuse or shared runtime/source-menu-slot lifetime cannot restore an old proof.

The proof provides native facade lifetime/admission identity. It is not proof
of completed battle simulation, original Init/End or reward transfer. Actual
completed return still requires the real retained completion owner's current
Done receipt, full pouch/result/runtime comparison and separate native field
return admission. Game host and Encounter copied-facade checks remain additional
requirements before any Game callback borrow.

Focused tests use actual `beginFromPouch` runtime construction with a clearly
marked TEST initialized prefix. They test copy construction/assignment while
the original is alive, redirected scene, moved facade, fresh entry and
replacement/old retained identity. No playthrough or teardown is inferred.

journal after its identity journal, then rebuild the complete coherent core.

# Native Mario position preadmission

`NativeFieldMarioGetPosition` binds the reached original
`evt_mario_get_pos800e71f8/c8` callback to a three-word native XYZ view. It reuses
whole `fieldMarioGetPosition`; it does not allocate a fabricated complete Mario
work area or change the original field event. Its only admitted argument shape
is `(0,LW0,LW1,LW2)`, actually reached by the fresh original Harbor beforebattle
root at command `905064c4`.

The binding pins the actual service userdata lifetime, host registration, actual
VM intrinsic registration and a pure actual-context current predicate. VM/host
proofs precede the predicate and every borrowed read. The Game predicate must
prove its actual current Game host slot, Encounter facade/VM and Harbor admission
before reading real storage. A copied facade/restore must not inherit that
admission. Lost identity latches stale. Recursive invocation and recursion from the current
predicate are rejected.

Native preflight checks the actual live entry registration and its E+18 argument
pointer, four known exact argument words and three known actual engine-unit
binary32 coordinates. Missing words, unsupported mode/destination, nonfinite
coordinates or an unsafe source `value * 1024` fctiwz domain return unavailable
before any source setter. An unavailable preflight can be retried because it has
not entered the source helper. This does not claim original speculative memory
read parity.

The three words are an immutable per-call native sample. Position/current
callbacks must be pure and the admitted native state remains stationary during
the synchronous helper. In this exact fixed-LW domain the actual source setters
write only the entry locals, so they cannot alias native Game XYZ or argument
cells. The helper captures arguments before its Mario owner query, then keeps
its original per-axis destination/read/write order, actual evtSetFloat old-local
read, binary32 multiplication, fctiwz truncation and source Q1024 rebiasing. It
uses the actual VM operands for context, entry, memory and truncation. The finite
semantic Mario token exposes only the three sampled XYZ lanes. Admission also
requires those lanes to be wholly unmapped in the actual VM; real owned or
unknown memory is never shadowed by this native view.

The XYZ callback has the same finite-view contract as
[Prepare/Post](RETAINED_MARIO_BATTLE_TRANSFER.md). Game can supply X/Z from actual
progress coordinates and Y from actual ground+jump, converted to engine units
under its current field owner. The encounter's projected actor slot is not a
source owner. No mode1 Y subtraction, encoded destinations, generic Mario memory,
full original field startup or normal activation is certified.

The standalone test covers actual VM LW stores/Q1024 output, missing-coordinate
holds without setters, finite conversion boundaries, unsupported destinations,
recursive calls, host destruction and VM destruction. The fresh-root test uses
actual original NPC/placement/event constructors and an explicitly labeled TEST
engine-space sample inside the real source trigger zone. It binds this callback
only; the next actual missing function remains unavailable. All legacy dialogue
and `HarborEncounter::begin` behavior remain unchanged.

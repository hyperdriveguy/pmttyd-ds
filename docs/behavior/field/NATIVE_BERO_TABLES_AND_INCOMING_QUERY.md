# Native original Bero tables and incoming query publication

This binds the selected-entry query values recovered in
[the complete source contract](../event/BERO_SELECTED_ENTRY_AND_INCOMING_LOCAL_BANK.md).
It does not complete get_info, original Bero child execution, or the
[house05 saved case bank](HOUSE05_INCOMING_LOCALS_AND_INSTALLER_FRONTIER.md).

## Original resources

`tools/bero_info_assets.py` selects each exact `bero_entry_data` symbol by its
original namespace: gor_01.o,gor_00.o,gor_02.o,gor_03.o,gor_04.o. It retains
all60-byte rows and the actual terminator, rather than reconstructing a table
from the reciprocal cardinal ROADv1 links. The five tables contain3/1/2/5/4
entries respectively. Gor02 includes both w_bero and dokan, so its original
count is2 even though only its cardinal road currently crosses to a packaged
outdoor room. Referenced script addresses remain original native-section aliases;
this pack does not acknowledge or execute their unbound bodies.

The scoped PMEVT data pack retains original row bytes/ADDR32 relocations and
name/destination strings, plus original DOL bero_null, direction-prefix table/
strings and20-byte default_entevt. The PMBRIO01 descriptor records room, original
table address, count and original named HitObj source IDs. Missing hit names
retain0 and cannot become fabricated native roads. These IDs are geometry
bindings, not Bero array indices. Original DOL addresses and REL native section
aliases follow the existing resource convention. No executable PPC is packaged.

## Query owner and real native caller

`FieldBeroInfo` owns the selected map view and a native incoming-name string
alias85000000. That address reads the actual retained string bytes; it is not
an original GameCube GP address or a host pointer. `intoInfo` publishes only
LW1..8 into a supplied EventEntry, preserving LW0,LW9..15 and all local flags.
The publication is a functional value binding; source raw memory/store alias
ordering and complete EVT callback dispatch remain separate work.

The query retains source selection and values: exact name matching/fallback,
actual table index/count, unsigned type halfword, unchanged explicit direction,
AUTO20000 ordered prefix matching (including no-match8), position pointer into
the actual row, entry-event pointer/default and ffff0000 inLW8. Empty incoming
name with live GP flag2 selects the first actual row and publishes its name
pointer; ordinary LW3 aliases the incoming-name buffer even on fallback.
It never replaces LW6 with copied/native-scaled XYZ or LW7 with a case handle.

Successful `Game::finishWarp` now publishes this query for the destination's
actual named entry/HitObj. It uses the live native system-flag adapter and the
original full table, independently of later Bero child completion. Ordinary
nonempty road names do not take the empty-name save-load arm. Missing data leaves
the query unavailable; it does not invent an incoming entry or erase an otherwise
valid existing native road adapter. Native boot requires the new data resource.
Checkpoint restore alone does not establish an incoming name. Area/resource
synchronization invalidates old publications; stale resource generations cannot
be read as current output. Invalid replacement assets preserve the last valid
resource bank. No new get_info reset of shared BeroEXEC is performed.

## Validation and remaining work

Host tests compare every original row/relocation and original fallback/default/
prefix bytes. Query tests cover ordinary road, pipe, missing-name fallback,
empty-name save-load arm, exact pointer reads, untouched caller words/flags,
room/resource invalidation and successful native Game arrival. A plain checkpoint
restore leaves publication unknown. Isolated native road evidence and exact
validation scope are recorded in [progress](../../PROGRESS.md).

Remaining: actual get_info HitObj checks/registration and shared globals,
current-number/party readers, original normal/pipe placement and SDK arithmetic,
later initial_pos outputs and save-load case allocation. Those paths write
additional high locals, including save-load LW13/14. This eight-word query is
not a complete incoming16-word bank and does not authorize house05 registration
with invented residual words. Door case snapshots, original open/close events,
key49 scene, material1800 consumers and additional area lifetimes remain open.

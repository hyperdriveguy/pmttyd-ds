# Native registered NPC setup world

Composes the existing [ordered setup mechanics](NPC_SETUP_ORDERED_INSTALLATION_AND_RETAINED_PROVIDER_FRONTIER.md)
with actual retained [NPC actors/poses](NATIVE_RETAINED_NPC_REGISTRY_OWNER.md)
and the [admission requirements](NATIVE_NPC_SETUP_WORLD_ADMISSION_REQUIREMENTS.md).
Original data is the read-only US G8ME01 revision0 pack; no dialogue or event
words are invented and no original executable PPC is interpreted.

`FieldNpcSetupBinding` binds one retained owner, its exact registry binding,
that binding's actual EventNativeRuntime memory, and an owned immutable source
pack. Foreign owner/facade combinations, missing clock or numeric/RNG providers,
and unknown F identity fail binding. The captured GP mode must remain stable;
invoke checks it and F again before source work. A rejected initial call retains
sourceFirst, so later first=false admission does not turn initial setup into a
resume poll. Source first/resume remains the original caller's state.

Before first-phase effects, admission checks the bounded original table and
its live unchanged words through its actual null-name terminator. It resolves
real active actors by name, admits descriptor strings and real pose resources,
initial animation readiness, exact init-script scanner inputs, safe deletion,
associated actor destinations and complete populated battle providers. Missing
actors skip only in source first phase; resume holds missing release lookups.
The table is not filtered or zipped with tagged-map ordinal order.

The immutable script check follows the source constructor's flat scanner up to
END with at most16 labels and bounded nonnegative argument counts. It verifies
all command/argument words, including the source scanner's unconditional next
word read even on END. It does not claim later USER_FUNC world readiness.
Native table/script bounds are admitted domains, not measured original limits.
The packed source bodies and original callback conditions stay unchanged.

`safeDelete` checks every active matching ID in the selected context and the
recursive waiting-child/owned-brother deletion closure. It holds when that
closure reaches the caller, unresolved/outside links, or cyclic/repeated graph
nodes. It permits ordinary independent-root deletion; it never substitutes a
successful source skip for unsafe deletion. Source parent copyback and actual
retirement still belong to the VM's real deletion service.

First-phase services run the real numeric npcSetBattleInfo helper, source
halfword fbatChangeMode through fresh GP/F, and real FieldPosePool SetAnim with
the caller's current explicit millisecond clock. The numeric admission callback
receives actual live memory, actor and index so it can prove its complete source
data/RNG/switch read domain. It must have no effects on false and supply all
needed synchronous operations on true. One externally retained shared RNG is
required; the binding never seeds or resets it. A correct cold seed does not
establish the [pre-Rogueport random state](../meta/ORIGINAL_RANDOM_STATE_INITIALIZATION_AND_WRITERS.md).

Resume admission stops at the first live init, matching the reached no-effect
poll domain and avoiding a full table/script scan on every waiting tick. Once
all inits are dead it admits actual installed actor+124 regular scripts and
safe old-regular deletion. Actual source creation uses independent roots,
actor+170, init/regular byte0/1 and flags0/20 through the retained scheduler.
Native event allocation/append capacity holds after required deletion, without
repeating flag ORs, metadata, RNG or animation work. The existing setup cursor
owns those stages; the binding supplies their real world operations.

`FieldAreaEvent::bindNpcSetup` installs this owned bridge after map registration.
It takes priority over a manually supplied NPC world and cannot replace an
already admitted invocation. It aliases the retained original Program's source
pack and uses that exact area VM, event IDs and registry. Room retirement first
clears referencing event/cursor state, then releases this adapter. Real source
table/script bytes, descriptors/pose ownership, event graphs and synchronous
providers must remain valid across admitted allocation holds; arbitrary external
mutation during a held invocation is outside this native domain.

Tests invoke the real service directly with actual constructed event entries,
original15-row npcEnt, real registered actors/poses and an explicit caller-supplied
fixture RNG state. They prove255 source draws,15 independent init roots, actual
execution of chusan3/roten3 RETURN/END, retained unknown-world init polls and two
regular roots after explicitly retiring pending fixture roots. That fixture
retirement does not claim those unbound init callbacks executed. They also test
bad admission/no draws, allocation holds, retained first, GP mode holds,
self/ancestor deletion, changed script rejection and actual area installation.
Earlier Bero/Mario parent services, all11 original init/regular callbacks,
normal Game activation, shared full-session draw order, query/Main/facing/GPU,
complete rendering/collision and hardware performance remain required.

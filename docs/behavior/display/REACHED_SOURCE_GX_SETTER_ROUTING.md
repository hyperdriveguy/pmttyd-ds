# Reached source GX setter routing and loaded profile snapshots

`SourceGxSetterRouting` connects actual reached source drawing services to the
same process [inherited GX history](SOURCE_COLD_GX_INHERITED_HISTORY.md). It is a
native metadata observer. **Its result never acknowledges an original child.**
An actual drawing/resource owner must first finish its own request, retaining
its partial work on a hold. Only an engaged/true result from that owner permits
`accepted(request)`. Preserve that original result; do not replace it with an
observer status or retry an already successful opaque prefix.

The router pins the actual shared history, independent strong source-scope
resources, and a real short source-current predicate. The queued weapon binding
uses its actual held frame/camera predicate, not an atlas, Game-active flag, or
invented source state. Reentry rejects before callbacks/effects. Retirement
prevents further recording/capture without destroying resources borrowed by an
in-progress callback. Short source loss does not retire an already loaded
packet's long process proof.

Adapters preserve operands from the actual existing service protocols:

- [Display dispatch](DISPLAY_QUEUE_AND_DISPATCH.md) records actual color/alpha
  masks, blend, Z mode/location. Original dispDraw80010900 calls color update at
  80010944; alpha0 at8001096c for camera4/5/7, alpha1 at80010978 otherwise.
  Identity Z scaling and alpha comparison do not change a tracked field.
- Class/submenu `BattleTexturePlaneRequest` records actual low GX calls; FIFO
  stores are observed without inventing another setter.
- Font state and DrawStart fog keep original function/callsite, color and exact
  binary32 bits. `__GXSetIndirectMask802b8880` does not establish NumIndStages0;
  it is transparent to this owner's distinct tracked fields.
- Source icon's fixed argument lanes use the original setter's operand count,
  preserving source fog color/scalars and swap writes/reset writes.
- Window requests combine the actual separately captured fog color with its
  original type/scalars, retaining the original callsite.

Requests whose transport has no callsite retain0; no source PC, register or
stack location is guessed. Explicitly known transparent leaf functions include
local TEV/channel/vertex/texture/matrix operations and pure camera/map queries.
They still require their real source/native owners. Opaque material/fog parents
are not silently treated as transparent. If an actual accepted operation cannot
be represented, future history is invalidated. A held/rejected operation never
enters this observer, so it cannot invalidate or mutate evidence prematurely.
The observer must be attached to the actual low GX child boundary, rather than
observing an already instrumented high-level parent again as an opaque effect.

`capture(1)` checks short source currentness before and after capturing the real
history. It returns a distinct immutable snapshot whose `current()` uses only
the actual long process proof. `compatibleNow` performs the same fresh check.
The snapshot allocation happens during source packet preparation, before native
mixed GPU submission. It is not called inside the prepared nonallocating GPU
loop. No glyph RNG, GPU draw, importer or source readiness write occurs here.

The Class6 and Submenu7 journals capture at **actual accepted LoadTexture**.
The current source query still checks the latest history. If capture is missing
or unavailable, the actual load remains held without replacing the previously
loaded object/profile. An accepted load copies its own immutable ordinary proof
into each resulting packet. Later legitimate circle/bubble/icon/font setters
cannot invalidate those loaded packets. Packet validation after camera.finish
uses the copied snapshot, never live GX state or overwritten callback userdata.
The class object's independent snapshot also attests the ordinary proof's
identity, preventing removal or replacement of its captured profile.

The optional capture hook preserves the existing explicitly supplied legacy
host fixtures. Production queued weapon queries must bind it and a real current
history check; omitting it is not a production ordinary-GX proof. Submenu packet
source resource identity and callback-proof ownership remain separate; the
additive journal composes with the runtime worker's sourceProofOwner journal.
No long callback borrows only a mutable/ephemeral frame Context. An immutable
snapshot owns its independent long process proof; allocation/resource guards
remain mandatory separately.

The finishing-camera journal observes real DisplayQueue requests only after
`finishingDisplayState.request` accepted them. It constructs a synchronous
observer pinned by the actual NativeUiStartup lifetime; the real dispatch call
is the source boundary, and startup currentness supplies its process guard.
This does not register a callback or manufacture an active battle camera pass.
The queued runtime worker owns the actual class/submenu/font/icon/window low
provider bindings and their real Frame scope guards.

Focused tests run the actual portable DisplayQueue with held state requests:
color's successful prefix is not replayed, held alpha writes leave history
untouched, camera4 alpha0 makes new capture unavailable, camera8 alpha1 restores
it. Other tests cover all six adapter shapes, source scope loss, reentry,
retirement, grayscale swap changes/restoration, original fog operands, opaque
accepted effects versus unaccepted holds, and historical snapshot survival.
The Class6 test journal extends its genuine original TPL/SDK source fixture with
held load-capture retries, copied-proof survival after later swaps/camera loss,
proof-removal rejection, and process retirement.

Strict host/sanitizer/ARM tests of the new observer are independent of old core
archives. Fresh source-only builds with a complete consistent private include
graph also execute the new Class6 original TPL/SDK/Circle per-load regression
and full Submenu7 packet tests plus the new per-load cases. Both pass under
ASan/UBSan, too. These host fixtures explicitly provide test camera/GPU imports;
they do not prove actual native residency or source CameraMain admission.
Changed packet layouts still require full integrated builds and runtime binding.
Actual source dispatch, source owners and whole ordered immutable
GPU submission remain required. No whole Weapon, ordinary battle/tutorial,
original PPC or physical-device activation is claimed by this module.

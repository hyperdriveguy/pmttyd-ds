Implements the captured-owner, unconditional16-GX-prefix and200-record admission
portion of [original DispAudience](AUDIENCE_CAMERA4_CLASS1_CLASS2_CALLBACK_AND_EMPTY_BANK.md).
The native ending dispatcher routes actual callback801a38f8 through a guarded
TrioAttack binding: invoking camera, callback and borrowed userdata must match.
Callback arguments do not select its source camera; camera4 is captured once.
BaseGetPtr's owner is retained before setup; GetPtr0 independently selects the
current battle after setup. Record pointer then advances by134 for200 actors.

Every iteration freshly asks the real display queue for its current entry.
Class2 rejects alpha255, every other class rejects alpha!=255. Flags are read
only after alpha admission and must contain1 and4. Alpha0 is not an additional
visibility gate. The native producer runs the original full setup4 audience
initializer; this callback does not clear actors, population, flags or colors.

A retained cursor remembers source step, record and index. Unavailable state or
current-entry providers repeat only that operation; acknowledged setup and
prior admissions do not replay. The first admitted actor holds inside801a38f8,
without advancing, requesting a fake texture or acknowledging its missing body.
Admission stays captured if flags/alpha change while this body is unavailable.
Nonempty palette/pose/quad continuation remains unimplemented in this binding;
independent world audience rendering is not the retained callback.

The shared native logical shader owner accepts original material-register
ChanCtrl(4,0,1,0,0,2,2), RGB TEXC+RASC and alpha TEXA*RASA. Citro3D uses ADD for
RGB and two native stages for texture alpha times material alpha. The source
one-stage equation is the same; PICA quantization remains an adaptation. The
source prefix changes no material, texture, masks, blend, depth, fog or camera
matrix. Unknown channel material remains unknown in the logical owner. In this
no-primitive domain, shader setup preserves the physical raster constant where
that owner is unknown; it does not fabricate a source material value. This is
not a valid native nonempty draw until actual channel material/texture/geometry
owners and continuation are bound. A real source dummy resets the audience RGB
equation. State restoration emits no primitive or callback acknowledgement.

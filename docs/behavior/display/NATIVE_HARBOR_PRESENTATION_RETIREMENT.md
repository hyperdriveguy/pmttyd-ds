# Native Harbor presentation retirement

`Renderer::retireNativeHarborPresentation` is an outside-frame native teardown
operation for the actual tutorial runtime. It rejects a foreign actual startup,
curtain, command-menu, Nice or smoke owner before retiring anything. Runtime
identity compares both pointer and shared ownership; a numeric scene is not proof.
Actual GPU FrameSync precedes native menu/frame invalidation, vertex/texture/shader
release, original startup-bank/curtain retirement, battle maps and actor atlases.
Original source display callbacks, effect-pool teardown and Sequence Main are not
acknowledged by these native resource operations.

The caller must retain its admitted NativeHarborCompletion owner and suspend
battle rendering across a held teardown. Otherwise normal battle preframe work
could reacquire the resources. Field return requires successful actual field-room
presentation admission and the canonical pouch commit before publishing the
unchanged completion receipt through the matching native field sequence owner.
This renderer contribution alone does not activate that production coordinator,
write a field result, restore controls, change story or complete source wait.
Source wait and the original afterbattle event remain separate actual VM work.

See [completion](../battle/NATIVE_HARBOR_COMPLETION_POLICY.md) and
[smoke](../effect/NATIVE_HARBOR_KEMUTEST_SMOKE.md). Native compile and full coherent
host/native gates cover integration; no native pixel or full round-trip proof is
implied by a host-only effect admission fixture.

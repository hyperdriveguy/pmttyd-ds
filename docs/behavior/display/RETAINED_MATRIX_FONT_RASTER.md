## Whole source controller and shared helpers

than provide a replacement width. Layout uses fresh GP language spacing and
source signed-word double-bias conversion before binary32 pen-X addition.

Unknown/unwritten bytes hold. A null parser return changes the subsequent read

## Genuine finite atomic glyph child

`drawSourceMatrixFontAtomicGlyph` supplies the normal original US inner glyph
raster using the existing WindowFont consumer, rather than acknowledging a
missing glyph. It requires the actual immutable MessageFont/resource/GPU owner,
live original BFN actor views, an actual effective TEV-color query, whole-quad
admission, real shared RNG and an infallible admitted ordered-quad sink.
The native `invoking` guard is owner metadata, never guest state, and rejects
recursive admissions. Strong owner and current checks precede effects.

For the actual original single byte, require native mapping to equal the source
mapped glyph. Read live WID1 bearing/width and active GLY descriptor fields;
compute original finite US cell coordinates and cropped height, and require an
exact match to the real atlas FontGlyph. Missing/mismatched font data, multibyte
or unsupported source-code domain rejects before RNG. Actual source fallback
glyph0 remains valid when both real mappings agree; no question mark or rewritten
text is substituted. Space width comes from the real setup-patched source data,
not a new hardcoded layout rule.

Pure geometry admission computes the one source signed16 quad and checks the
whole sink capacity before drawing. It executes no fake or preliminary RNG.
After admission the existing one-byte MessageDirect consumer receives the
actual source glyph coordinate and performs the two **real** irand64 calls,
then emits one actual quad. This is reuse of a matching inner primitive;
the outer controller still uses StringMatrix float-pen semantics. Outline work
is five separate child requests/quads with ten real RNG draws, not a baked
outline texture. The sink cannot fail,reenter,mutate resources or invalidate
its owner after admission. Retrying a failed admission consumes0 RNG and emits0
quads. Effective TEV color is the color already established by the source GX
owner; recomputing it from subsequently changed raw/alpha state is incorrect.

This atomic adapter is an explicit finite native presentation policy. Its
current proof must cover the original US atlas, current matrix/TEV/font texture
lease and ordinary font shader profile. Unsupported noise/rainbow/material
profiles remain unavailable until their original attributes have actual owners.
It does not claim to reproduce ignored HSV/noise FIFO attributes or arbitrary
PowerPC FPSCR/NaN behavior. The [inner primitive contract](../message/FONT_GLYPH_QUADS.md)
describes those wider source boundaries. Actual clipping may suppress final
GPU visibility but cannot suppress the two source RNG calls.

existing font-manifest offset, keeping setup width writes7 then9 only in their
private fixture copy. They compare all256 source mappings and all162 live widths

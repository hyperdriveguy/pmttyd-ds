# Harbor stationary jump admits its own encoded position

2026-10-13 scoped native correction. The harbor encounter's original event
reads Mario's root through the existing source get-position callback, which
stores each component with setEventFloat. That recovered operand service
multiplies in binary32 by1024, truncates toward zero, stores the biased encoded
word and decodes it with the reciprocal1024. Arbitrary native field positions
therefore do not necessarily equal their resolved event operands.

The stationary native jump adapter previously compared resolved target X/Z to
the unencoded root, leaving the original event waiting indefinitely for roots
such as(0.12345,15,-100.875). It now compares only to that root's exact Q1024
round-trip. It retains the same bounded stationary jump Y/physics, source
operands, original message IDs/order, parameter/flag admission and battle-start
wait. It does not broaden admission to a general destination or invent source
travel/height/30Hz behavior. Native root X/Z remain unchanged during this scoped
stationary jump; original sub-Q1024 travel/raster parity remains unproved.

Validation: the existing original-data encounter regression exercises positive
and negative non-Q1024 roots through the three original messages, setup2 and
original battle request. The further field-walking fixture still fails before
reaching the encounter trigger; no complete walked route is claimed by this
correction. See [native HUD/menu scope](../display/NATIVE_BATTLE_HUD_AND_SUBMENU.md)
for this session's separate presentation changes.

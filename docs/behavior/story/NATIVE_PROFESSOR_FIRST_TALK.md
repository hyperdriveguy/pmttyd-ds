# Native original first-talk execution

[Source chronology](PROFESSOR_FIRST_TALK_AND_FENCE.md) and
[used item/jump/turn services](PROFESSOR_ITEM_POSE_JUMP_AND_TURNS.md) are the
behavior baseline. [Asset relocation](../../../tools/professor_event_assets.py)
pins the US gor.rel and first-talk hashes, copies source sections and applies
actual ADDR32 local/module0 relocations. Section bases0x90000000+i*0x100000 are
authored native addresses, not recovered Dolphin load addresses. Original180
event commands and original strings are preserved in ignored local packs.

[ProfessorStory](../../../source/professor_story.cpp) executes those words in
EventNativeRuntime. The existing interpreter owns brothers, shared flag waits,
integer/float operands, event credit, milliseconds/frames and GSW0 writes.
The scoped catalog admits35 original callbacks. The119 callback starts and17
camera requests remain observable. No hand-authored replacement conversation,
flattened message sequence or source byte rewrite runs the scene.

The exact story8 professor door callback starts the scene before door completion,
so source NPC placement occurs before its door wait. Native input remains locked
until the original event ends. All29 message IDs, party `_kur` resolution,
speaker roots and control bytes use msg/US/gor_02.txt. Original source cameras,
Mario event poses (including e_mario M_C_3), source item0x60/icon314/TPL319 and
BGM_EVT_FRANKURI1 are bound to handheld presentation. NPC no-hit jumps use the
225ms/height30 parabola; movement uses a named linear speed adapter. Source
story9 is read from the VM's actual GSW0 assignment, not independently invented.

Native rendering reuses room-cached Frankly models, original Goombella poses,
source-font windows and cached print-entry anchors. The source map icon uses a
native billboard sizing/orientation adapter. Mario's separate scene atlas is
resampled to62px cells with1px padding in512x512 RGBA8, bounding its allocation
to1MiB. Geometry/animation/UV domain remains source-derived. Scripted movement
uses explicit facing targets; pure-depth motion retains its previous facing.

Limits: reaction icons, camera shake, original voice/fall SFX, display-bit and
NPC/party flag consumers are retained typed presentation requests rather than
complete backend implementations. The jump's flag preservation, exact NPC
matrix/facing smoothing, turn counter/interpolation, source NPC/party movement
and collision stepping, audio fades/environment mix and item icon service
details remain open. Temporary Frankly party1 is represented at the source saved
position, with follow/lifecycle still unbound. Saves including exit saves are
suppressed while that temporary state cannot be serialized. Fence removal,
story10 lecture dispatch and source lesson/battle branches remain separate
required work; first-talk completion is not full prologue parity.

[Original-data tests](../../../tests/professor_story_tests.cpp) check door wait,
all29 IDs/order,119 callback starts,17 cameras, source hop peak, original item
scale, music restoration, source story9, in-game admission/control restoration
and save suppression. They prove this scope, not original hardware/GX/SDK/FP
or complete effects equivalence.

# Native spotlight allocation and ending stage pass

Uses original [work/Entry/Init/Main/Free](STAGE_SPOTLIGHT_WORK_INIT_AND_MAIN_ADMISSION.md)
and [mutable colour bootstrap/help admission](SPOTLIGHT_MUTABLE_COLOUR_BOOTSTRAP_AND_AC_HELP_ADMISSION.md).
Source data table802f37a8 and DOL literals already exist in the unchanged local
event pack. No new image, texture or invented ISO-backed BSS colour is imported.

Native maps the actual separate twelve-byte SBSS work8041ebdc and mutable
colour804295d4. The original initialized pointer804175a0 is read from source
data and checked against the mapped owner. A per-Game session history starts
zero, survives room/checkpoint `restore`, and supplies later battle startups.
Standalone trio runtimes create independent boot state unless supplied a
session owner. Live source memory publishes count/bank/gate and colour after
Init/Main and runtime destruction; the history is not a serialized save or
an additional live address-space alias. Future writers must use live memory.

StageWork storage, named StageObjectInit and spotlight Init now execute in
source order. Init writes count5, actually allocates dc bytes through the map
heap, rereads global ownership around callbacks, clears the bank, performs five
Entry/default-colour writes and overrides from the original template/literals.
The single FMA uses a native numerical adapter; no source timing/GX/FP parity
claim follows. Work8 is preserved. Entry retains flags except OR1 and consumes
the first free slot; the original valid-domain capacity requirement remains.

Main reads the real count and signed gate. Its empty positive-count loop has
no record operation and is omitted. Nonpositive gate finishes; positive gate
requests actual camera6/class0/callback80137d20/user0/priority-1000 display
registration, whose native renderer remains explicitly unbound. Free uses the
real map heap and preserves all original work fields; StageEnd/BattleEnd have
not yet been bound, so the native bank remains allocated at the ending hold.

The ending engine pass now completes spotlight Main and twelve actual inactive
StageWork entries/four zero counters. AcHelp checks actual key/mode/Bef4 fields
and requires its original display registration when admitted. Its setter,
window activation and active draw services are separate work. Fresh ordinary
endings pass those real predicates and reach AudienceMain801a836c. This step
does not bypass audience/slot/display, report complete engine teardown or
release field result/control/story state.

values, zero-to-white colour order, other flag preservation, first free slot,
owner rereads after allocation, retained gate on reinit/free, display admission
independent of count and active record flags, provider suspension, per-session

endings inspect the real bank, changed EndingWork allocation history, ordered

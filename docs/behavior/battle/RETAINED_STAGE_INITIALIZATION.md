# Retained battle stage initialization

`battle_stage_init_continuation` owns the complete original US
`BattleStageInit80139780/e4`, `BattleStageObjectInit80149bd0/8d4` and
`batSpotInit80138068/138` bodies. The original ISO is read-only; the verifier
pins those bodies, the complete spotlight-entry leaf, pure pointer getters and
initialized source tables. Static recovery and host execution do not claim
execution of the original PowerPC program or a completed native tutorial.

The outer owner invokes the existing source stage-work storage initializer,
then its retained object and spotlight children. It preserves the original
floor, lighting and twelve work-record stores; no source phase, display flag or
battle result is supplied by this module. See the [cold startup
contract](HARBOR_SOURCE_STARTUP.md) for the native parent boundary.

## Objects and linked children

The object initializer captures the actual battle global, stage setup, selected
count and descriptor pointer before clearing the 32 records of 124 bytes. It
retains the independent pouch/rank reads, including the additional fresh rank
read inside the rank-cache branch. It owns all selected, decoration, escape-wall
and built-in scans, copied vectors/templates, ordinal/flag writes, event-count
conditions and final audience/interface visibility bits. Selected/decorative
full-bank scans stop; the original mandatory wall/built-in scans reuse the last
record when no free record exists. This behavior is preserved rather than
replaced with an invented capacity error.

Actual map lookup/animation/group-flag operations, unit entry, event entry and
battle allocation use typed requests carrying original function, callsite and
integer arguments. These are whole retained linked-child boundaries, not opaque
branch handlers. Engaged zero is an original return value; no result is native
unavailability. A void child's engaged result is permitted only after that
actual child completes. Providers must retain their own successful prefix.
`SetPos80128c6c` and `SetHome801289a0` use the existing complete vector helpers;
the pure pouch and stage pointer getters execute their real memory accesses.

The source does not request native geometry here. A matching atlas or hierarchy
file is neither completion of MapGetWork nor a reason to acknowledge a missing
map/event/unit child. `MapGetWork8002b438` is the actual process-global base at
`8041e660` plus the word at `8041e664` times its `2f4` bank stride. The caller
must provide that actual process/map owner or an explicitly reviewed native
address-view adaptation; an invented original pointer is not admitted.

## Spotlight and numeric operations

Spotlight initialization reads the original initialized pointer at `804175a0`,
publishes count five, requests count times the 44-byte record stride and
recaptures the work pointer before publishing the allocation and clearing it.
It invokes the complete existing `batSpotEntry80137a88/94` five times, including
its fresh process color read, halfword active bit and template copy order. It
captures the source position words before the two optional arithmetic
boundaries. The original signed-index double subtraction rounded to binary32
and the fused binary32 multiply-add are separate retained providers. Each
successful operation and store is retained across a later hold. Work offset
`+8` is left unchanged.

The actual game already owns a process-lived `BattleSpotlightState`, retained
through Game restore. A future native binding can expose that same owner's
three work words and entry color at the original views `8041ebdc` and
`804295d4`, with proof of process birth/history and lifetime. It must use the
pinned initialized DATA pointer, share every actual VM write and avoid a fresh
per-battle default instance. This portable owner does not assert that a new
zero-filled mapping proves original CRT/SBSS execution.

## Admission, holds and original Crump domain

Each cursor retains the full service identity, shared ownership control block,
original private captures and pending request. Recursive entry/reset is
rejected. Changed owners/providers cannot resume a held invocation. A failed
current-owner predicate latches unavailability until explicit metadata reset;
reset writes no guest state. Parent/child completion never advances simulation
ticks or supplies a renderer acknowledgement.

`BattleActorServices` memory accessors are total. The native caller must admit
all reached actual source/read/write domains before calling, keep RAM topology
and ownership stable throughout synchronous accessor sequences, and hold
outside the owner when a required source byte is unknown. In particular, raw
spotlight work/color and map-root pointer chains cannot fall back to private
zeros or abort on an unknown source mapping. The optional linked/numeric
providers are the recoverable pause boundaries; this API does not turn total
word access into an optional memory protocol.

The original Harbor stage at `95540870` (gor.rel offset `608f8`) selects four
24-byte descriptors at `955407e0`: A1/A2/B/C, layers 0/1/2/3, all category 2.
Their source XYZ values are `(33,0,-48)`, `(0,0,71)`, `(0,0,0)` and `(0,0,0)`.
At the actual ordinary rank-zero branch there is no unit entry, rank animation
or stage event: all five source event fields are zero. The complete object
result has those four rows plus escape_wall and spotlight. Its foreground name
is `stg_00_0`; the required original hierarchy must be provided by its real asset
owner. This closed domain does not justify accepting absent names or fabricating
MapGetWork state. Other ranks/stages retain the full branches and their genuine
external child requirements.

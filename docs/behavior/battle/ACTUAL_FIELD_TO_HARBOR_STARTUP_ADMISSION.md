# Actual field-to-Harbor startup admission

`BattleSequenceBinding` can bind one native `HarborSourceFieldServices` table.
Binding snapshots the table and retains its resource lifetime; later mutation of
a caller's mutable alias cannot replace held callbacks. Rebinding the same
original shared owner is idempotent; another object or ownership identity
rejects. Binding providers performs no source initialization or scene mutation.
Unavailable resources belong in the reached child response; `current` proves
resource-owner lifetime, not loading completion.

Only the actual `800f8f04(F+20)` request from original field initializer
`800738ac` phase 36 constructs `HarborSourceFieldAdmission`. No source frame is
activated by binding the table or obtaining the owner. It requires the completed
[actual pool producer](NATIVE_SOURCE_NESTED_POOL_ADOPTION.md) and
[actual camera producer](ACTUAL_FIELD_BATTLE_CAMERA_RECEIPT.md) on this exact VM.
It captures the actual shared camera manager and NPC owner, and verifies the
NPC's actual VM aliases. The information operand must be that actual owner's
F+20. Intrinsic VM registration and producer lifetime checks precede borrowed
VM access. Native source aliases/resource lifetime are checked again after the
external pure current predicate. Observed ownership loss permanently holds the
owner.

The first reached call uniquely adopts the already-produced nested map pool.
It constructs the existing retained `HarborSourceStartup` with that pool and
actual VM. The original ColdInit allocates BattleWork, stores its address to
8041eb90, clears/initializes source fields, and executes its original children.
The admission layer never allocates a second arena, registers fixed B/U/P
mappings, seeds source information, starts legacy `HarborTutorial::begin`,
registers actors by hand, copies a scene into source memory, or samples controls.
Menu source reads/stores are derived from this actual VM; native root/format/file
callbacks still require their own genuine current resource owners.

Held retries retain the same pool claim, Startup cursor, original information
operand, BattleWork allocation token and child's private request. Neither a
successful allocator nor a completed menu/file prefix is repeated. Getter
availability means a held startup owner exists; `coldComplete()` remains false
until all real original children complete. `resumeUnitSetup(B)` is a distinct
later actual child entry and refuses before ColdInit completes or for a different
B. Obtaining this API does not acknowledge Main, UnitSetup or any event.

The independent proof owns the adopted pool and resource table. Startup retains
this proof without owning the containing admission owner, so there is no
owner→Startup→owner cycle. Destroying the Binding, Game or actual VM rejects
retained admission handles before any borrowed access. FieldNpcRegistryBinding
has its existing retire-before-VM contract: the caller must retain it while F+20
is in use and detach it before VM destruction. Admission checks its aliases and
holds if they disappear; retaining NPC bytes alone is insufficient.

If native Harbor services are absent, the binding preserves its existing real
external BattleInit provider path. This increment does not install any normal
Game startup switch or legacy tutorial facade. The old facade embeds a different
VM and publishes visual scene fields into source state; it must not be used as
this owner's implementation. Source-controlled event routing, Flow/Main cadence,
physical input, display pass composition and field return remain separate actual
owners.

Provider frontiers remain explicit:

- Earlier real animation, NPC release, party/information and event-context children
  must finish before the production field initializer reaches BattleInit.
- Menu root/format/file providers require the real process/DVD/resource path.
  The fixture's actual FileCache bank is a TEST native resource adapter.
- Stage, audience, break-slot and Noise children use only caller-supplied actual
  retained owners. No empty-name Noise policy or successful defaults are installed.
- Native animation/resource and equipment providers remain required for UnitSetup.
- The source event registry, original dialogue/message providers, source poses,
  action commands, menu rendering and controller/result/export/teardown are not
  implicitly bound by this admission layer.

Tests execute real source Init, camera/pool producer calls and the exact retained
field callsite. An explicitly labeled TEST fixture positions the native parent
at phase 36 after the genuine unavailable animation prefix; it does not certify
or acknowledge skipped children. Exact original constant/format bytes are read
from the existing original resource pack, preserving its own NUL. Original root
bytes come from the read-only ISO initialized data at the actual source R2 leaf
result; the fixture does not synthesize a root string. No source
information or scene fields are synthesized. Tests cover missing-menu hold,
actual held Stage request identity, no allocator/file replay, caller-table mutation,
late configuration, original ReInit, real allocation free/reuse, alias retirement,
resource loss and Game/VM/Binding destruction. This is not a normal opening-to-
Crump execution trace or a playable/tutorial-completion claim.

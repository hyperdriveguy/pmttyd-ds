# Native Harbor positive reward flow

This finite native policy coordinates the actual reward counter and Renderer
reward model. The caller supplies an independently owned current proof, actual
victory stream admission, actual source key40 root admission and actual root
completion query. It supplies no synthetic guest End work or field receipt.

After positive counter and presentation admission, victory music is admitted
once. Original ending08 falls through09:120 becomes119 in the same simulation
visit. Later visits decrement to0. The next visit creates the actual victory
root, enters PointGet and starts the counter, with no point transfer on that
entry visit. Source0b starts counting on the following visit and does not wait
for the victory root. The original intro camera/audience requests remain
separate services; this model does not claim the complete source08 dispatch.

The counter owns actual pouch writes and physical held A/B mask0x300. This
coordinator retains a held operation's original tick/input through later outer
ticks, including sound holds after a successful EXP store. Repeating the outer
tick that completed a retained operation has no additional side effects. Each
accepted visit advances the real presentation model once. Successful memory,
root and music prefixes are retained across later unavailable services.

On ordinary count/cooldown Done, hide all nineteen icons and soft-delete the
actual PointGet model. Wait the original five ordinary cleanup visits. An
additional native admission guard requires the actual victory root to have
retired before ReadyForFinishing. PointGet's independent leave clock continues;
its disappearance is not substituted for the five-visit delay. ZeroReward and
LevelUp have distinct blocked branches and cannot become ReadyForFinishing.
This class is noncopyable and rejects stale or reentrant owner callbacks.

words loaded from the ISO-backed tutorial pack. They check9 EXP, normal and
physical accelerated cadence, source row boundaries, held external accesses,

disabled. Native audio/GPU/physical victory, finishing/fade and field return

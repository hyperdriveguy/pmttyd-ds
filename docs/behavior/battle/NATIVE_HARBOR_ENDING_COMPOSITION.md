# Native Harbor ending composition

The native main loop composes the actual admitted Harbor facade/runtime,
Renderer reward model and generation-owned battle/victory music. Its stationary
owner captures the immutable facade proof before any Game borrow. Callback
userdata has an independent shared proof with weak owner; no owner cycle or
copyable Game-owned raw callback is introduced. Replacement invalidates admission
before stopping the old actual stream generation and releasing its proof.

One genuine simulation visit follows Game.tick outside FrameBegin. Battle music
is admitted once using the actual runtime/proof. Actual source conclusion1 then
requests the guarded real counter and Renderer model. Missing hardware/audio,
resource, counter or victory-root children remain held. Counter admission retains
its one-shot latch; dropping a failed UI owner cannot re-award the same battle.

The flow starts real owned victory music, runs the actual key40 victory root,
updates the actual nine-point pouch counter and native nineteen-icon/PointGet
model. Physical held A/B is read from Game's real general pad channel. Held
service prefixes preserve their original tick/input while later fixed ticks
continue. Audio lifecycle services only the actual admitted battle/victory
generation; a retired receipt means silence and cannot restart legacy track12.
Actual Audio.play still services owned PCM births on ordinary main-loop visits.

This contribution activates the positive reward flow only. ReadyForFinishing
continues PointGet's leave clock; it does not mint an ending/field-return receipt
or alter Harbor.scene.result. Source finishing, fade, both-screen submission,
synchronized resource teardown and fresh field admission/return remain separate.
Zero/level-up and unsupported party domains are not completed by this owner.

The focused test uses the real Game, scene, source key40 event, actual counter,
pouch and presentation. A TEST-only conclusion/old-root setup admits that domain;
Renderer and Audio backend admission are explicit test boundaries. It verifies
unavailable GPU/music holds, nine actual EXP writes, original victory pose/root
retirement, PointGet exit and stale facade retirement without duplicate starts.
Host, changed owner/runtime ASan/UBSan and ARM owner syntax pass; other core
objects are not instrumented, leak scanning disabled. Main-loop and actual
hardware integration require fresh make test/all/native physical acceptance.

# Harbor source cold startup binding

`HarborSourceStartup` composes the retained [whole cold constructor](BATTLE_COLD_INIT_CONTINUATION.md)
and [unit setup parent](BATTLE_UNIT_SETUP_CONTINUATION.md) with the actual
[map allocation owner](HARBOR_SOURCE_MAP_POOL.md). It owns their cursors and
retains the exact delegated request across a missing stage, audience or
break-slot provider. Reentry, changed field-information inputs, replaced map
allocations and retired source owners cannot restart accepted work.

The cold parent publishes its actual returned allocation through the original
source global. The native adapter does not install a fixture BattleWork alias.
The nine [closed storage children](BATTLE_COLD_STORAGE.md) execute their full
source bodies. Whole `btlDispInit801030f8` initializes the source BattleWork
camera work, resumes original common-menu file entry, then sets the original
`ef8` flag. This camera work is distinct from the shared camera manager mode
producer `8000e95c(4,2)`; it grants no camera, draw queue or GPU receipt.

Unit setup uses actual pouch storage, complete home/position copies, resource
import and original no-item equipment paths. Its retained
[unit construction owner](HARBOR_SOURCE_UNIT_CONSTRUCTION.md) executes each
original Entry, including repeated group entries at the same source callsite.
Nonzero equipment requires its real provider. Missing original animation
resources hold the genuine pose Entry without replaying the constructor.
No legacy actor registration, pose readiness or field result substitutes for
those children. The source resource/menu owners
must remain alive for the binding; actual battle teardown owns their release.

The focused actual-VM test imports the original Harbor event image and common
TPL through the real file cache, allocates/publishes original cold storage and
holds at actual StageInit `80139780`, callsite `800f901c`. Repeated resumes
preserve the same request and menu reference. Its field-information record is
a test-owned memory fixture, not an observed original encounter. This verifies
CPU ownership and cold prefix order, not native battle entry or a playthrough.

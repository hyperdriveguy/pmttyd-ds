# Native temporary Frankly following

US G8ME01 revision0 static source evidence. The source story8 first-talk tail
creates temporary party slot1 kind11 from saved integer coordinates, then enables
party run. Kind11 binds `c_kuri_h` and the same `partyMoveWalk` callback as ordinary
party locomotion. The pending initialization selects the secondary history bank.
See [used lifecycle/admission](FIELD_PROFESSOR_TEMPORARY_PARTY_AND_FENCE_ADMISSION.md),
[constructor/callback](FIELD_PARTNER_WALK_CALLBACK.md),
[history source selection](FIELD_PARTNER_HISTORY_WRITER.md) and
[scene lifecycle](../story/PROFESSOR_FIRST_TALK_AND_FENCE.md).

`secondaryPartyUsesOther` preserves the source bank1 selection: other party
missing, kind3/mode3, status3, or ordered Mario-to-other distance>=150 original
units selects Mario; otherwise selects the other party. For this slice the other
party is ordinary Goombella. The unordered distance comparison is preserved.
Native source selection uses3D distance, including Y, and original units.

`Game::updateTemporaryProfessor` owns an independent PartnerFollow history and
terrain state. It runs once per simulation tick after Mario/Goombella movement,
including door travel, outside the locked first-talk scene. It reuses imported
wall/floor queries and camera projection, source ordinary speed-control constants
and the existing [path/jump/fall adapter](FIELD_PARTNER_NATIVE_FOLLOW.md).
Frankly's source-space root feeds the existing original model renderer; moving
selects W_1, resting S_1, and horizontal travel updates source yaw90/270.

This is a functional native adapter. The existing vector trail is not the exact
80-record source ring. Ordinary Goombella kind1/running mode1/status0 are explicit
inputs; complete party modes/status services, flag consumers, recovery owner
differences, exact motion/facing/pose lifecycle and source time ordering remain
open. Frankly is retained only in room2. Saves remain suppressed until temporary
party serialization or source conversion back to NPC is bound. The original
story9 professor-house close callback owns fence admission; following neither
changes story9 nor substitutes a proximity trigger for that event.

Original-data scene tests complete the conversation, walk Mario for100 simulation
ticks, verify Frankly has independent initialized history and changes position,
and retain story9/save suppression. Source-selection checks cover threshold,
missing/special party cases and unordered comparison. No new Dolphin trajectory
or physical3DS validation was performed.

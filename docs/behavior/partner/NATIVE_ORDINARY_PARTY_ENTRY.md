# Retained native ordinary Goombella construction

`NativeFieldPartyEntry` binds original marioPartyEntry801412fc, EntryMain800be144,
partyEntry800bea68 and the fresh ordinary10 Hello branch. Production battle
ending owns one instance across waits. It replaces the previous inline block
that could allocate another actor after an unavailable animation/material/placement
provider. Existing primary removal uses `NativeFieldPartyLifetime` and its actual
source file release before construction. It does not complete battle exit.

Evidence: original US revision0, complete bodies freshly recovered read-only in
`artifacts/field-party-entry-evidence/` (ignored), hashes matching
[entry/appearance order](FIELD_PARTY_ENTRY_FIRST_APPEARANCE_ORDER.md),
[animation admission](FIELD_PARTY_ENTRY_ANIMATION_ADMISSION.md) and
[native removal](NATIVE_PARTY_REMOVAL.md). This is static evidence, not an
original-game execution or hardware timing measurement.

The bound domain is ordinary kind1, canonical pouch join bit, stable typed Mario,
registry and shared animation owners, complete normal original source data and
fresh Hello state10 with word8 bit8 clear. Other kinds, d_mario, unknown source
callbacks and other Hello branches retain explicit unavailable boundaries.
Ordinary Entry's both-slots-full/null-wrapper failure domain is not repaired:
native admission waits for a real free slot before allocation. Auxiliary13
Entry2Pos and authored join events remain separate work.

The caller checks the existing join bit before any removal. A nonnegative primary
index causes the second Mario query, retained Kill and explicit ff publication.
A negative result from the join gate has no unlock/removal/allocation effects.
Main publishes one zeroed188-byte actor, initializes original camera/event/owner/
kind/saved-kind fields, captures its resource, and retains that actor and child
arguments through Entry/PeraOff/material waits. The positive source pose handle
comes from the real shared native animation factory. Legacy host checkpoints
retain their original CPU animation workspace backend; they cannot simulate file
release when replacing a live partner.

After PeraOff, P160 is captured once. Two independent marioAnimeId calls index
that same Mario owner; each getter handle and returned mask survives its later
wait. Each setter captures fresh Pc after the getter. Names come from the
unchanged original normal row and strings. HP is signed/live at each of three
selection visits, with <=5 selecting12. Both Main strcmp blocks remain distinct;
selected pointer is retained, the second block still compares with fresh8000 set,
and only its differing/null result then checks8000 to suppress repeat writes.
Actual mapped NUL-terminated bytes determine equality, including distinct aliases;
unavailable strings hold captured operands. P1c clears once, then fresh global
definition and its reached initializer are retained independently across waits.

Original initializer dimension reads/stores, vector word publication and the two
separate display-angle queries precede placement. First placement/previousXYZ/
pose/mode completes before Mario245 publication. Fresh Hello performs a second
placement and live HP/pose selection. A placement service becoming available does
not replay construction, materials, the first display reads or an already completed
placement while a later strcmp waits. The source placement helper's false result
is ignored, as in the original caller; missing providers remain unavailable.

Native appearance uses the existing value-output math/ray adapter. Its production
providers do not inspect or mutate intermediate actor/output aliases. XYZ becomes
visible in the actor after the helper returns; source-visible intermediate output
writes to arbitrary reentrant providers are outside this binding. Host/ARM math
rounding is not claimed Gekko-identical. Trace actor operands retain this port's
slot convention; encoded raw actor addresses belong to the lifetime VM adapter.

An expiring native entry lease excludes another allocation or removal after actor
publication. It neither adds original flags nor changes original event state.
Changing the registry's native animation/pool during an invocation rejects resume.
Caller owners must remain stationary; active copying/moving/cancellation and
external raw actor destruction are unsupported. Destruction only expires the
lease and never dereferences borrowed Game members or invents source completion.

Tests cover actual native Entry/file-release waits, warm replacement, unavailable
material getters/setters with captured masks/owners, delayed placement, retained
string operands and geometry, signed HP boundaries, first/Hello publication order,
callback/global-definition capture, unknown initializer and join gates. No test
asserts full story/field return, visual parity, all Hello states or measured speed.

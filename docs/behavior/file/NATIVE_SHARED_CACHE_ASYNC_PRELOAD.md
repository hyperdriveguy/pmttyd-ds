# Original async preload in the native shared cache

`requestPackedFile` retains complete US fileAsync80189d44 over admitted backed
memory and leaves. Source scalar0 completes this invocation; unavailable children
retain the source cursor. Source hits are filename-only, skip state0, return0 on
pending and otherwise return the actual entry, changing only state2 to3. No
reference, holder, type or completion argument is acquired/replaced on a hit.

Misses retain available entry/NEXT and source archive-mode dispatch. Archive
publication preserves the actual live-head reload after clearing retained E.a4;
it does not substitute captured NEXT. DVD publication preserves length rounding,
close before allocation, state3/count0/C, used-list publication before second
open, actual pending token, request leaf and unconditional raw0. First-open0 is
source-1; missing native catalog entries instead hold before source effects.

`submitPackedDvdRead` performs literal request word/halfword stores including
separate flag rereads. `completePackedFile` uses actual used-list pending+40
lookup, retains D, clears pending before effects, handles only exact result-3 as
state2/type0b, and otherwise relocates actual holder payload, closes and then
reads live E.a8. Unknown callback holds after acknowledged prefixes; missing
source callback match remains an unchecked source domain, never a benign skip.
Services and memory stay admitted/stationary; this is not a general fault engine.

NativeFileCache shares its existing actual FilePool, smart holders and original
MODEL/TPL backing across synchronous acquisition, preload and every VM facade.
Each staged file has a distinct native backed DVD record. New preloads queue
actual staged bytes and return source0 with state3/count0. `advanceAsync` copies
at most its explicit byte budget across pending files, then drives original
completion/relocation/close. That budget and explicit pump boundary are native
cooperative ROMFS policy; no original DVD worker/thread/interrupt latency is
claimed. Source Entry/acquisition takes its first reference separately afterward.

Smart holder H04 now contains the rounded backed payload size; H00 remains its
actual data and source allocation writes H08 backlink. This supplies the actual
AG2TG count read by animGroupBaseAsync, which previously would see zero.
Pending `_fileAlloc` yields hold instead of spinning under the default provider;
the external native IO pump can progress while that same acquisition remains
retained. Its current file and shared filename are restored after each worker
visit. Request/acquisition/worker calls serialize; no arbitrary reentry or
concurrent thread domain is admitted. GC, movement and eviction remain unbound.
New user completion callbacks currently require C0; unsupported C holds before
new publication. Direct source fixtures cover callback mutation/hold semantics.

`requestAnimationGroup` ports complete animGroupBaseAsync80039d0c: exact mode
archive selection; MODEL type5 with original C; fresh W100/holder/count/payload
reads; signed byte-offset comparison and first equal32-byte lane; actual
following lane texture or source empty literal; unconditional TPL type4/C0;
then original raw-result precedence. A source0 starts a fresh next invocation;
a held child retains captures and does not replay acknowledged requests.

AnimationGroupRequestBinding uses the actual same-VM holder/table/payload and
same NativeFileCache. Every native visit proves exact physical backing identity;
byte-identical foreign caches cannot substitute. Formatting and comparisons are
bounded native adapters (128-byte terminated input; immutable string domain),
not a claim about optimized SDK string load/fault order. The verified original
US empty SDA2 literal8041fb30 has four zero bytes outside the older cold boot
image; bind supplies exactly that source constant in previously unmapped VM RAM
or validates an existing zero word. No AG2TG dictionary or converted table is
introduced. Original formats/prefix are read from the existing cold image.

Tests cover raw result combinations, native holds, mode/argument pinning,
first equal lane, scan miss/negative count, request/completion cache effects,
actual MODEL/TPL pending records, pending acquisition versus worker completion,
two-VM sharing and foreign-cache rejection. Five original harbor models preload
through actual AG2TG, then take original pose Entries over those same holders.
This does not execute original EVT Entry/SetTribe, create original story actors,
or prove source Game/GPU/audio/event scheduling, visibility or full prologue.
The next binding must pump IO and resume retained invocation owners before the
Game animation clock gate; it must retain source0 polling versus native holds
